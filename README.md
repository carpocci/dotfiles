# Andrea Carpino's dotfiles

## Setup

Clone this repository in your home directory:
```git clone https://github.com/carpocci/dotfiles.git ~/.dotfiles```

Install the dependencies and set up the environment:
```~/.dotfiles/install.sh```

## One-liner installation

If you want to install everything in one command on a debian-like system, you can run:
```sudo apt update && sudo apt install -y git && git clone https://github.com/carpocci/dotfiles.git ~/.dotfiles && ~/.dotfiles/install.sh```
